# 2004sp - Runescape 2 PS2 Port

Runescape 2 brought to the Playstation 2.

Includes support for 2004sp Singleplayer mod, or vanilla Lost City

Based on Revision 254

## Features

- Full 2004 Runescape Experience on Playstation 2
- Self Hosted Server with player bots support, custom content
- Adapted for the Playstation 2's hardware specifications and low memory limit
- Cross platform
